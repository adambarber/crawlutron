# Funding

crawlutron is distributed under the MIT license and is free to use, modify, and
redistribute. There are no sponsors, paid tiers, subscriptions, or hosted SaaS
offering, and this document is not a solicitation.

## How to contribute instead

The project is sustained by adoption and contribution, not revenue:

- report reproducible bugs and concrete feature requests at
  https://github.com/adambarber/crawlutron/issues;
- review pull requests and improve the documentation;
- submit tested changes following `CONTRIBUTING.md`.

No financial support is accepted, so there are no sponsor banners or funding
targets to publish here. Security reports follow the path in `SECURITY.md`.
