# Governance

crawlutron is an MIT-licensed open-source project (see `LICENSE`). There is no
foundation, paid membership, or formal steering committee; the maintainer is
@adambarber, as recorded in `.github/CODEOWNERS`.

## How decisions are made

- Changes are proposed as pull requests against `main` and reviewed in public.
- Security-sensitive code requires explicit maintainer review, as described in
  `CONTRIBUTING.md`.
- Discuss design and direction at
  https://github.com/adambarber/crawlutron/issues before large changes land.
- Participants are expected to follow `CODE_OF_CONDUCT.md`.

## Distribution and support

The project is released as source and wheels, is free to use under the MIT
license, and is provided without warranty. `SUPPORT.md` describes where to ask
questions and how to report a vulnerability; `FUNDING.md` states the funding
posture. Release versions are owned by the process in
`.github/workflows/release-please.yml`.
