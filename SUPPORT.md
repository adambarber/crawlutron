# Support

crawlutron is a self-hosted, MIT-licensed service. There is no managed hosted
offering and no paid support plan; support is best-effort and community-driven.

## Where to ask

- **Bugs, feature requests, and usage questions:** open an issue at
  https://github.com/adambarber/crawlutron/issues. Include the version, the
  request or configuration involved, and the observed versus expected result.
- **Documentation:** start with `README.md` and the references in
  `docs/references/` (agent contract, manual test plan, telemetry).
- **Security vulnerabilities:** do not open a public issue. Follow the private
  advisory process in https://github.com/adambarber/crawlutron/blob/main/SECURITY.md.

## What to expect

General issues are answered as maintainer time permits; there is no response
time commitment. Security reports follow the separate acknowledgement and fix
targets stated in the security policy. This project is distributed under the
MIT license and provides no warranty, as set out in `LICENSE`.
